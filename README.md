# Warsztat AI — skille agentowe

*(EN: An open part of my AI-agent workshop — 110 agent skills for Claude Code. Polish-first.)*

Otwarta część mojego warsztatu pracy z agentami AI (Claude Code): **110 skilli** obejmujących
metodyki pracy, wzorce implementacyjne (Next.js, Supabase, React), automatyzacje,
marketing i sprzedaż B2B na rynku polskim oraz orkiestrację wielomodelową.

Narzędzia rozwijane od 2025 r. w prywatnym repozytorium, na realnych wdrożeniach.
Upublicznione **4 lipca 2026 r.**

## Struktura

Każdy katalog = jeden skill: `SKILL.md` (instrukcja dla agenta) + opcjonalnie
`references/`, `scripts/`, `assets/`. Instalacja: skopiuj katalog do `~/.claude/skills/`.

## Integralność i pochodzenie

- Nazwy klientów z wdrożeń zanonimizowano placeholderami (`ClientA`, `ClientB`, `Hotel Demo`).
- Kryptograficzny dowód istnienia pełnego warsztatu (manifest SHA-256):
